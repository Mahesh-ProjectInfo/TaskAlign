# Task Align - Project Rules

## Project

Task Align is a Spring Boot web application that optimizes resource-to-task assignments using the Hungarian Algorithm.

The finalized SRS, Database Design and API Design are the single source of truth.

Do not redesign the architecture.

Implement only according to the finalized documents.

service

mapper

exception

validation

security

util

Do NOT create module-based packages.

---

# Coding Rules

Always generate production-ready code.

Never generate pseudo code.

Never generate incomplete methods.

Never regenerate existing files unless modification is requested.

If an existing file needs changes, modify only the necessary parts.

Always preserve compatibility with previously generated code.

Always mention:

- File Path
- File Status (New / Modified)
- Integration Notes

# Integration Rules

If another member's entity is required:

Do NOT create it.

Use temporary Long IDs.

Example

Long assignmentTypeId

Later replace with

@ManyToOne AssignmentType

Document every integration point.
